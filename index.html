02 / FAQ

Questions, answered.

A few useful notes about this project archive.

Where are my projects stored?

Published projects are loaded from data.json. Your existing browser projects are also kept as a migration fallback, so anything you already entered on this browser continues to display while you move to GitHub-backed storage.

Will this work on GitHub Pages?

Yes. The site remains static HTML, CSS and JavaScript. GitHub Actions updates data.json when you submit the pre-filled Project Hub sync issue, so no GitHub token is exposed in the browser.

Can I still add, edit and delete projects?

Yes. Type the private command addproject anywhere outside a form field to open the glass Add Project modal. Edit and Delete continue to work from each project card and sync their changes through GitHub Actions.

Does the theme preference persist?

Yes. Light and dark mode continue to use the existing theme_pref localStorage preference, with improved system-aware styling and transitions.

What happens if an image fails?

A built-in SVG placeholder is used instead of an external placeholder service, and an error notification explains what happened without breaking the rest of the archive.
